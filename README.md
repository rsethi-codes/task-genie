# TaskGenie: 2026 AI Task Management System

TaskGenie is a premium, AI-driven task management system designed for Gen-Z and power users who demand intelligence, beauty, and fluid performance.

## 🧠 Design Philosophy

- **AI as a Collaborator**: The UI reflects the intelligence of our AI core. It’s not just a tool; it’s a productivity partner.
- **Motion as Communication**: Every animation serves a purpose: providing feedback, reinforcing hierarchy, or signaling AI activity.
- **Minimalist Complexity**: We prefer clean, focused layouts that reveal depth through interaction.
- **Futuristic Aesthetics**: Deep blacks, neon accents, and glassmorphism create a high-end, next-gen feel.

## 🎨 Theme System

TaskGenie features a robust, runtime-switchable theme system built on CSS Variables and Tailwind 4.

### Preset Themes:
- **Cyberpunk (Default)**: Deep Slate & Electric Cyan
- **Forest**: Emerald Green & Natural Tones
- **Sunset**: Red-Orange & Warm Highlights
- **Midnight**: Indigo & Deep Gray
- **Monochrome**: Pure Black & White (Zero Distraction)

## ✨ Motion Philosophy

Powered by **Framer Motion**, the application feels alive:
- **Spring-based physics** for natural movement.
- **Staggered animations** for smooth layout entry.
- **Micro-interactions** on buttons, cards, and toggles.
- **AI Thinking Indicators**: Glowing pulses and typing animations.

## 🛠 Tech Stack

- **Next.js 16 (App Router)**: Bleeding edge React framework.
- **TypeScript**: Type-safe development.
- **Tailwind CSS 4**: Modern CSS-first utility framework.
- **Framer Motion**: Advanced animation engine.
- **Clerk**: Seamless, secure authentication.
- **Lucide React**: Clean, modern iconography.

## 🚀 Key Features

1. **Intelligent Dashboard**: Personalized greetings and AI strategy suggestions based on current energy levels.
2. **Master List**: High-performance task management with list/grid views and expandable AI insights.
3. **Genie AI Chat**: Globally accessible AI interaction for real-time task decomposition and scheduling.
4. **Autonomous Settings**: Granular control over Genie's autonomy and UI motion intensity.
